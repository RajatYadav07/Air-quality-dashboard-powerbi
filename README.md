# Air Quality Dashboard - Power BI

A comprehensive Power BI dashboard analyzing air quality data in India.

## Overview

This project contains a Power BI dashboard (`Rajat Bi CA.pbix`) that visualizes and analyzes air quality metrics across Indian regions. The dashboard provides insights into various air quality indicators using the India Air Quality consolidated dataset.

## Files

- **Rajat Bi CA.pbix** - Main Power BI dashboard file
- **Air quality dataset/** - Folder containing the raw dataset
  - `india_air_quality_consolidated.csv` - Consolidated air quality data for India
- **Rajat Yadav Power BI report CA2.docx** - Detailed report documentation
- **Rajat Yadav Power BI report CA2.pdf** - PDF version of the report

## Dataset

The dashboard uses the `india_air_quality_consolidated.csv` dataset which contains comprehensive air quality metrics across different locations in India.

## Features

- Interactive visualizations of air quality data
- Regional analysis and comparisons
- Time-series trends
- Key metrics and KPIs

## How to Use

1. Download or clone this repository
2. Open `Rajat Bi CA.pbix` in Power BI Desktop
3. Refresh the data connections if needed
4. Interact with the visualizations and filters

## Requirements

- Power BI Desktop (latest version recommended)
- CSV dataset files
